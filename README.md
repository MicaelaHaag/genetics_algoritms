# Algoritmo genético: evolución de una frase con tres métodos de selección

Materia: Técnicas, Entornos y Aplicaciones de Inteligencia Artificial (UNRN)
Autores: Haag, Micaela Belén

## Ejecución (Ubuntu)
    sudo apt install python3 python3-tk
    python3 codigo/algoritmo_genetico.py

Solo usa la librería estándar de Python (Tkinter). No hace falta pip.

## Contenido de la entrega
- codigo/algoritmo_genetico.py : código fuente (selección por ruleta, torneo y ranking)
- presentacion.pdf             : diapositiva de la exposición del 28/9/2026
- link_video.txt             : link al video con la ejecución y la explicación del código

## Controles
Iniciar/Pausar, Paso (una generación), Reiniciar, frase objetivo editable (3 a 14 letras),
sliders de población, k del torneo, mutación, elitismo y velocidad, y la casilla
